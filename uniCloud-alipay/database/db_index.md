# 数据库索引配置

在 uniCloud 控制台 → 数据库 → 索引管理 中手动创建以下索引：

## order 表
| 字段 | 排序 | 唯一 | 用途 |
|------|------|------|------|
| time | 降序 | 否 | 列表排序 orderBy('time', 'desc') |
| user | 升序 | 否 | 搜索 keyword 匹配 |

## albums 表
| 字段 | 排序 | 唯一 | 用途 |
|------|------|------|------|
| name | 升序 | 是 | 创建/更新时唯一性校验 |
| createTime | 升序 | 否 | 列表排序 |

## photos 表
| 字段 | 排序 | 唯一 | 用途 |
|------|------|------|------|
| albumId | 升序 | 否 | 按相册查询照片、聚合统计照片数 |
| createTime | 升序 | 否 | 照片列表排序 |
